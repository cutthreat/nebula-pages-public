NEBULA Screen Compare Board

Интерфейс для поэкранной сверки `верстка / эталон` по product-family страницам NEBULA. Переключение идет по странице, экрану и адаптивной версии. Для экранов, у которых уже есть отдельный Figma export, слева показывается точный screen reference. Для остальных экранов слева строится честный crop из full-page эталона по той же пропорции страницы.
