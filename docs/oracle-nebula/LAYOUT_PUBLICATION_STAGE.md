# Oracle/Nebula Layout Publication Stage

Layout publication is one stage of the global Oracle/Nebula delivery plan.

This stage means:
- the selected local pages are bundled from `_unzipped/home.html`;
- their first-level local page links and required static assets are published to the GitHub-backed public preview;
- external preview URLs are smoke-checked after publication.

This stage does not mean:
- page-level design acceptance;
- user-review acceptance;
- production deploy approval;
- completion of the full Oracle/Nebula objective.

Acceptance still requires source-vs-live comparison, breakpoint checks, residual review, and Head/owner decision for the exact page scope.
