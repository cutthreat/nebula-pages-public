# Yii2 integration boundary

The source reference `http://127.0.0.1:8173` is used for source/route provenance only. This package is a static projection for layout, linking and responsive QA.

Not established by this package: live authentication/session ownership, credit balance, payment execution, consultation timer/debit, message persistence, realtime transport, notifications delivery, deletion capability, or production deployment. A programmer integrating the package into Yii2 must bind each route from `manifest/route-matrix.json` to the current controller/view/resource contract and rerun host-rendered QA.
