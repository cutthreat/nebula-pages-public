## Confirmed repair

`Next suggestion` previously only scrolled the rail. It did not change `aria-selected` or the message draft. The shared chatroom JavaScript now selects the next/previous suggestion, updates the draft, focus and disabled state. The fix is present in the source, experiment host route and published handoff asset; `node --check` passes.
