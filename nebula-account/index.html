Nebula Cabinet + Chat

Локальный интерактивный preview текущего Yii2-контура. Здесь работают клиентские состояния, клавиатура, фокус, draft и host-intent события. Реальные отправка, платежи, сессия и сохранение данных намеренно не имитируются.

Как проверять: откройте экран, включите DevTools → Responsive Design Mode и проверьте 1200 / 992 / 768 / 576 / 320 px. Для inspector используйте ссылки с ?fixture=1.
